Pixels (px): Fixed size → width: 300px; means the element is exactly 300 pixels wide. Percentage (%): Relative to the parent element → width: 50%; means the element takes up half the width of its parent. Viewport units (vw): Relative to the browser window → width: 100vw; means the element spans the full width of the screen. Auto: Browser decides based on content → width: auto; lets the element grow or shrink naturally. Max-content / Min-content / Fit-content: Advanced sizing based on content → width: fit-content; adjusts to fit the content snugly. Why Use Multiple Fonts?
